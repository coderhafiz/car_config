# customly-U - 3D Real-Time Car Configurator

An interactive, high-performance 3D automobile configurator built with **Next.js 15**, **React Three Fiber (Three.js)**, **Tailwind CSS**, and **Framer Motion** for **customly-U**.

![customly-U Studio Configurator](public/og-image.png)

---

## 🚀 Features

- **High-Fidelity 3D Vehicles**:
  - **Audi R8** (2023 Edition)
  - **Audi RS6 Avant** (2020 Edition)
  - **Audi RS8 Sport** (2023 Edition)
  - **Porsche 911 Carrera 4S (992)** (2023 Edition)
  - **Chevrolet Corvette C8** (2025 Edition)
  - **Lamborghini Revuelto** (2024 Edition)

- **Photorealistic Architectural Showroom**:
  - Procedural micro-cement showroom interior with realistic diffuse and bump textures.
  - 3D channel-letter illuminated **customly-U** wall logo pulsating in electric blue (`#026dfe`).
  - Dynamic directional studio wash lights and spotlights that cast real-time blue illumination and specular highlights onto the vehicle.
  - Realistic overhead Superloop ring light and contact ground shadows.

- **Deep Customization Options**:
  - **Exterior Finishes**: High-gloss metallic coats and ultra-matte performance finishes with fine-tuned PBR roughness, metalness, and clearcoat properties.
  - **Wheel & Brake Packages**: Custom alloy finishes and brake caliper accents.
  - **Interior Cabin Styling**: Custom leather upholsteries, Nappa leathers, and Nero Corsatex finishes.
  - **Interactive Controls**: 360° orbital rotation, cinematic zoom, smooth camera transitions, and exterior/interior view toggles.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **3D Engine**: [Three.js](https://threejs.org/) via [@react-three/fiber](https://r3f.docs.pmnd.rs/) and [@react-three/drei](https://github.com/pmndrs/drei)
- **Animation & Transitions**: [Framer Motion](https://www.framer.com/motion/) & [Maath](https://github.com/pmndrs/maath)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons & UI**: [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/coderhafiz/car_config.git
   cd car_config
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm run start
```
